### Required repository filename

Before Phase 1 static implementation begins, export/copy that exact approved binary mock into this folder as:

```text
lina-homepage-approved-2026-08-29.png
```

Do **not** recreate the mock from memory. Do **not** substitute an older `v2-*`, `v3-*` or `v5-*` screenshot.

The approved mock is a **target, not inspiration**. Coding agents must compare browser screenshots against it during visual QA.
